# book-data-analysis
Data analysis of book ratings to help a librarian decide which types of books to stock more of, using Python (pandas), SQL, and visualization.

## Questions

1. Do non-fiction books receive higher average ratings than fiction books?
2. Do authors who write in one genre receive higher average ratings than authors who write across many genres?
3. Is there a relationship between a book's page count and its average rating?
4. Do older books have higher average ratings than newer books?
